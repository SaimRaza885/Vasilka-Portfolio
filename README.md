# Vasilka Vlaykova — Portfolio

A static React/Vite portfolio website prerendered into clean HTML.

- `pnpm dev`: Start the local development server.
- `pnpm build`: Build the site and generate HTML for every portfolio route.
- `pnpm start`: Preview the production build.
- `pnpm check`: Run the TypeScript check.
- `pnpm format`: Format source files with Prettier.

The site has no backend, database, authentication, or API layer. Portfolio content lives in `src/data/`.
